# ✨ Piano de Luz

**Una experiencia musical interactiva donde cada toque se transforma en sonido, luz y movimiento.**

Piano de Luz es una aplicación web experimental que convierte la pantalla en un instrumento musical visual. Permite crear melodías libremente mediante una escala pentatónica, mientras cada nota genera haces de luz, partículas, ondas expansivas y efectos luminosos.

Desarrollado con HTML5, CSS3 y JavaScript puro, sin frameworks ni dependencias externas.

## 🎹 Demo

🚀 **[Probar Piano de Luz](https://YoanLeyva.github.io/piano-de-luz/)**

## ✨ Características

- **Piano interactivo:** diez zonas musicales basadas en la escala pentatónica mayor de Do.
- **Audio sintetizado:** generación de sonidos en tiempo real mediante Web Audio API.
- **Efectos visuales:** partículas luminosas, ondas expansivas, destellos y haces de luz.
- **Glissando:** desliza el dedo o el ratón para recorrer las notas y crear secuencias musicales.
- **Multitáctil:** permite interactuar con varias zonas simultáneamente en dispositivos compatibles.
- **Estrellas ambientales:** fondo animado con estrellas que generan una atmósfera espacial.
- **Efectos de audio:** armónicos, filtros, compresión y eco para enriquecer el sonido.
- **Control de sonido:** botón para activar o silenciar el audio.
- **Diseño adaptable:** compatible con pantallas de escritorio, tabletas y móviles.

## 🛠️ Tecnologías utilizadas

| Tecnología | Aplicación |
|---|---|
| HTML5 | Estructura de la aplicación |
| CSS3 | Diseño, animaciones y efectos visuales |
| JavaScript ES6+ | Lógica e interactividad |
| Canvas API | Renderizado gráfico y animaciones |
| Web Audio API | Síntesis y procesamiento de sonido |
| Pointer Events API | Interacción táctil, ratón y multitáctil |

## 🚀 Cómo ejecutar el proyecto

No necesitas instalar dependencias ni configurar un entorno de desarrollo.

1. Clona el repositorio:

   ```bash
   git clone https://github.com/TU_USUARIO/piano-de-luz.git
   ```

2. Accede a la carpeta:

   ```bash
   cd piano-de-luz
   ```

3. Abre `index.html` directamente en tu navegador.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para ejecutar el proyecto en un servidor local.

## 🎼 Cómo jugar

1. Abre la aplicación.
2. Toca o haz clic sobre cualquier zona de la pantalla.
3. Escucha la nota y observa los efectos visuales.
4. Desliza el dedo o el ratón horizontalmente para cambiar de nota.
5. Experimenta combinando diferentes notas y movimientos.
6. Utiliza el botón de sonido para silenciar o activar el audio.

**Consejo:** no necesitas conocimientos musicales. La escala pentatónica permite experimentar libremente con combinaciones de notas que mantienen una sonoridad agradable.

## 📱 Compatibilidad

- Navegadores modernos basados en Chromium.
- Mozilla Firefox.
- Safari.
- Dispositivos Android e iOS compatibles con Canvas y Web Audio API.

El audio se inicializa después de la primera interacción del usuario, siguiendo las restricciones habituales de reproducción de los navegadores.
